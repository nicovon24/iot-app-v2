# Referencia visual: Municipios Argentinos

Capturas aportadas por el usuario el 2026-10-20 para orientar el rediseño cartográfico de IoTArg:

- [Argentina](municipios-argentina.png): provincias extruidas, selección, etiquetas, leyenda de altura y controles.
- [Buenos Aires](municipios-buenos-aires.png): detalle de subdivisiones, contexto atenuado y volumen visible.

Fuente indicada por el usuario: [municipiosargentinos.net](https://municipiosargentinos.net/). El sitio no cargó desde este entorno durante la revisión; solo se inspeccionaron las dos capturas. Son material de referencia de diseño, no cartografía ni assets de la aplicación.
